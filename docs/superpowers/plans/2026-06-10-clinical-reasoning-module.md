## House-style reference (read before writing content)

- Section schema: `{ "title": string, "content": markdown-string, "keyPoints": string[] }`. `content` uses `\n\n`-separated markdown: `**bold**`, `- ` bullets, and `| a | b |` tables. Cross-links use `[[module-id|Display Text]]` or `[[module-id]]`.
- Numeric/guideline claims carry an inline source in running text, e.g. "(Clark 2018)", "(Maron JAMA 2023)", "(2021 International TSC Consensus, Northrup et al.)". **Accuracy is the top priority: every number and every guideline-derived interval must carry a source, and anything unsourceable is cut, not hedged with "often/may/can."**
- Reuse already-verified numbers from sibling modules verbatim (see `data/modules/diagnostic-yields.json` for yield figures and `data/modules/epilepsy.json`, `data/modules/iem.json` for precision-treatment examples). A restated number must match its source module exactly.
- Quiz items are vignette-style; `answer` is a 0-based index; every item has an `explanation` that teaches via the distractors. Match the depth of `diagnostic-yields.json` quiz items.

- Frame as a decision tree / branching logic, NOT a yields recap. Branch on: (a) phenotype specificity (well-defined single-gene-ish syndrome → targeted/single-gene or panel; broad/undifferentiated → exome/genome), (b) trio availability (severe early-onset, de-novo-enriched → trio doubles yield, OR ~2.04, Clark 2018), (c) repeat-disorder suspicion (→ dedicated repeat testing, NOT WES/WGS), (d) CMA-first scenarios (multiple congenital anomalies, IESS — CMA 14–25%), (e) turnaround urgency (acutely ill neonate → rapid WGS/WES, 35–50%, Maron JAMA 2023).

## Task 4: Write Section 3 — When "Negative" Isn't Negative

**Files:** Modify `data/modules/clinical-reasoning.json` (section index 2)

**Content brief (the highest-yield "don't close the case" section):**
- A negative report is time-stamped, not permanent. Four under-the-radar reasons a true cause was missed, each paired with the corrective action:
  1. **Database immaturity** → reanalysis at 12–24 months yields new diagnoses in ~10–25% of unsolved cases (cite as in `diagnostic-yields.json`).
  2. **Repeat-expansion blind spot** → short-read WES/WGS misses Friedreich (FXN GAA), SCA (CAG), CANVAS (RFC1 AAGGG), FXTAS (FMR1 CGG), DM1/DM2, HD (HTT CAG), C9orf72 → dedicated RP-PCR / Southern blot / long-read.
  3. **Methylation/imprinting disorders** → not seen on sequence: Angelman/Prader-Willi, others → methylation-specific testing (MS-MLPA), and SNP-array for UPD.
  4. **Mosaicism / non-blood tissue** → somatic mosaic overgrowth (PIK3CA, AKT3) may need deep sequencing or affected-tissue biopsy; standard blood WES can miss it.
- Add: deep-intronic/regulatory/structural variants → genome or RNA-seq.
- Cross-link `[[diagnostic-yields]]`, `[[mosaicism]]`, `[[epigenetics]]`.

Write `content` (~2000–2800 chars) structured as a "blind-spots" table or paired list (*what was missed → why → the fix*). Write 5 `keyPoints`.
